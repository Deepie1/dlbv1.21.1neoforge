Aura de Terreur (enchantement d'armure)

permanent

Accordé par

Enchantement dread_aura sur une pièce d'ARMURE

Lecture

Anneau bas, à mi-mollet (y + 0.32), le plus sombre du lot.

Commandes

Glisser pour tourner, molette pour zoomer.

Modèle

— · le joueur fait 1.8 bloc, le repère bleu indique son regard.

Les cubes sont posés aux coordonnées exactes du code : mêmes rayons, mêmes nombres de points, mêmes couleurs, mêmes alphas.
